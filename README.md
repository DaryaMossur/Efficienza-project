# Efficienza - Web-Based Project Management System

**Efficienza** is a web-based application designed to support project management by organizing projects, tasks, team members, deadlines, and analytical information.

## Repository Contents
This repository contains supporting materials for the project:
- **Demo Video** - a demonstration of the application's main features and functionality.
- **Software Specification** - project description, system functionality, and technical documentation, including SQL scripts for database table creation.

## Project Purpose
The application was designed to support IT project management through a web-based interface.

## Project Type
This project was developed collaboratively as part of a Bachelor's degree in Software Engineering.
